# Rewards System

> **Status:** Proposed implementation guidance, not an institutional commitment. Panther Passage is a competition concept for Philander Smith University. All sample people, events and services are fictional/simulated unless explicitly labeled externally verified.

Five crests, one per chapter. They signal completed **preparation**, not social rank. The achievement dataset maps chapter IDs to icon paths. Points (25 core / 15 optional) are purely decorative and never determine access. No streaks, paid features, leaderboards, shame nudges or punitive locks. Crest can be recalculated from actual task completion; each crest shows a short story about skills practiced. The finale is an earned threshold, not a credential.
