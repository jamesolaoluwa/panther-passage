# MVP Scope

> **Status:** Proposed implementation guidance, not an institutional commitment. Panther Passage is a competition concept for Philander Smith University. All sample people, events and services are fictional/simulated unless explicitly labeled externally verified.

## P0 for competition demo
Welcome, goal onboarding, home, responsive interactive journey map/list view, 15 authored milestone pages, task completion/unlock, counts, 3 demo personas/reset, resource browse, mock event RSVP, achievements, saved plan/reflection, graduation finale.

## P1 after core polish
Search resources, reduced motion preferences, print/export personal plan, route transition polish, optional real scheduling mock.

## Excluded
Production database/SSO, AI personalization requiring PII, external calendar bookings, real university systems, sensitive data collection, unapproved partnerships.

## Definition
All routes work offline with bundled demo data; no dead buttons; no fake network activity; predictable state.
