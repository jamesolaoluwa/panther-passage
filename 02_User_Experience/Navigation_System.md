# Navigation System

> **Status:** Proposed implementation guidance, not an institutional commitment. Panther Passage is a competition concept for Philander Smith University. All sample people, events and services are fictional/simulated unless explicitly labeled externally verified.

## Mobile
Sticky 4-item bottom nav with labels and clear active state. Ensure content bottom padding > nav height plus safe area. Subpages include real back link; completion returns to map with node focus restored.

## Desktop
Sidebar or horizontal header with same major destinations; chapter rail allowed on journey page.

## Navigation rules
Unknown milestone IDs show recovery page; deep-linked locked milestones display why locked and link to prerequisite; profile switch returns home; reload preserves route and local state. Tab order follows DOM reading order.
