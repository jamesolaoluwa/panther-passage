# Jobs To Be Done

> **Status:** Proposed implementation guidance, not an institutional commitment. Panther Passage is a competition concept for Philander Smith University. All sample people, events and services are fictional/simulated unless explicitly labeled externally verified.

1. When graduation feels big and vague, I want one relevant next step, so I can act without feeling overwhelmed.
2. When I make progress, I want to see what I have prepared, so I can trust my momentum.
3. When exploring post-college options, I want clear, non-judgmental comparisons, so I can choose a path without feeling locked in.
4. When I need a connection or resource, I want a clear starter action, so I can initiate contact respectfully.
5. As I leave college, I want to honor what I learned, so my transition feels like a beginning rather than only an ending.
