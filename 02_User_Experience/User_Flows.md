# User Flows

> **Status:** Proposed implementation guidance, not an institutional commitment. Panther Passage is a competition concept for Philander Smith University. All sample people, events and services are fictional/simulated unless explicitly labeled externally verified.

### First entry
/ → Get Started → /onboarding → choose fictional profile/pathway → /home → Start Journey → /journey → M01 → complete tasks → mark milestone complete → success overlay → /journey.

### Progressing
/home → next available node → /journey/M08 → save practice artifact → complete → crest update where eligible → /resources → filtered resources.

### Events
/resources → /events → open event → local RSVP → confirmation labeled 'Demo RSVP saved on this device'. Capacity full disables RSVP, cancellation restores one spot.

### Final
/journey → M15 (after required prerequisites) → complete and save promise → /destination → read highlights → restart/demo reset or go to /next-chapter.

### Edge paths
Back navigation, offline reload, invalid URL, storage unavailable, partially completed milestone, optional milestone skipped, date passed, motion reduced, keyboard-only controls.
