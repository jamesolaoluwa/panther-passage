# User Stories

> **Status:** Proposed implementation guidance, not an institutional commitment. Panther Passage is a competition concept for Philander Smith University. All sample people, events and services are fictional/simulated unless explicitly labeled externally verified.

| ID | Story | Acceptance criteria |
|---|---|---|
| US01 | As a new student, I can start without an account | Get Started opens onboarding; can proceed with fictional demo identity |
| US02 | As an exploring student, I can choose a pathway | Goal stored; resource emphasis changes but all core milestones available |
| US03 | As a student, I can see days remaining separately from progress | Both metrics present with distinct labels |
| US04 | As a keyboard user, I can activate any unlocked node | Every node reachable via keyboard and announced appropriately |
| US05 | As a student, I can save milestone work | Refresh restores completed tasks and notes |
| US06 | As a student, I can RSVP to a simulated event | Capacity validated; RSVP toggles in local state only |
| US07 | As a student, I can reflect privately | Reflection visibly marked private and local to this demo device |
| US08 | As a judge, I can reset three scenarios | Reset deterministic, no data leakage between profiles |
| US09 | As a student, I can reach a final destination | All required prerequisites plus M15 yield final ceremony |
