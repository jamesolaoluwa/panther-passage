# Accessibility Checklist

> **Status:** Proposed implementation guidance, not an institutional commitment. Panther Passage is a competition concept for Philander Smith University. All sample people, events and services are fictional/simulated unless explicitly labeled externally verified.

- [ ] Skip link and landmarks
- [ ] Unique meaningful page h1 and breadcrumb/back links
- [ ] Visible focus and focus restoration
- [ ] Labels / descriptions / errors programmatically associated
- [ ] Screen reader alternatives to visual route and crests
- [ ] Keyboard can activate every relevant node; no trap
- [ ] Status semantics do not depend on color
- [ ] Rendered text/icon contrast audited
- [ ] 200% zoom and 320px reflow
- [ ] Target size and spacing
- [ ] Motion reduction / no auto-playing sound
- [ ] Form validation and confirmation accessible

Reference: WCAG 2.2 AA, https://www.w3.org/TR/WCAG22/
