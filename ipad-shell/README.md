# Panther Passage iPad shell

Thin Expo SDK 53 wrapper for recording. It does not reimplement the product. It loads `https://panther-passage.onrender.com` in a full-screen WebView.

```bash
cd ipad-shell
npx expo start --ios
```

Recording device: iPad Pro 13-inch (M4) Simulator, portrait.

To point at a different URL, set `expo.extra.webUrl` in `app.json`.
