# Layout and Spacing

> **Status:** Proposed implementation guidance, not an institutional commitment. Panther Passage is a competition concept for Philander Smith University. All sample people, events and services are fictional/simulated unless explicitly labeled externally verified.

8px-based foundation with 4px microspacing. Tokens: 0,4,8,12,16,20,24,32,40,48,64,80,96. Mobile content side padding 20px; tablet 32px; desktop max-width 1200px, side gutters >= 48px. Journey viewport mobile 390px with horizontal positions clamped to padded content; desktop two-column chapter context and scrollable map. Cards radius 16/24, buttons radius pill/12, focus rings 3px outside. Minimum interactive height 44px; hero compositions should not block reachability of Start CTA.
