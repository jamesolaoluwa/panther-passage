# Typography and Type Scale

> **Status:** Proposed implementation guidance, not an institutional commitment. Panther Passage is a competition concept for Philander Smith University. All sample people, events and services are fictional/simulated unless explicitly labeled externally verified.

## Direction: Expressive Collegiate Editorial
- Signature: **Recoleta Black/900-inspired** rounded expressive collegiate serif. Actual Recoleta file and license are **not supplied**. Never download a random commercial font or imply free redistribution. If licensed unavailable, use `Georgia, serif` and tune letter spacing/size.
- Body: **Manrope** (proposed open-source choice, acquire verified license separately) for clean readability and contrast. Fallback: system sans/Arial.
- Editorial pullquote: Georgia italic.
