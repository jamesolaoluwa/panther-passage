# Imagery and Illustration

> **Status:** Proposed implementation guidance, not an institutional commitment. Panther Passage is a competition concept for Philander Smith University. All sample people, events and services are fictional/simulated unless explicitly labeled externally verified.

## Supplied
Original abstract arch welcome scene, 5 chapter arch compositions, five vector crests, winding SVG path, texture, provisional logo-mark. These can ship as prototype *illustrations* but none assert factual campus appearance.

## Missing approved media
Approved wordmark and logo files, approved UI screenshot, original full-quality campus imagery, verified campus arch source, university marks and any licensed typefaces. Do not scrape and pass off campus photography as first-party assets.

## Treatment
Prefer composed vector illustration over lifestyle stock. Imagery should feel architectural, nearly ceremonial, sunlit and clean with restrained foliage. Text overlays require tested contrast; set image alt text based on informational role, not generic 'image'.
