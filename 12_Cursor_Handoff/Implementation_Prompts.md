# Implementation Prompts

> **Status:** Proposed implementation guidance, not an institutional commitment. Panther Passage is a competition concept for Philander Smith University. All sample people, events and services are fictional/simulated unless explicitly labeled externally verified.

### Prompt 1 — scaffold
"Build a mobile-first Next.js TypeScript frontend for Panther Passage from the existing docs and JSON files; implement tokens and a local demo profile switcher. Do not yet assume approved logos or live integrations."

### Prompt 2 — journey engine
"Implement a pure progression engine from the milestones/tasks JSON, keyboard-accessible winding SVG path and list fallback; separate countdown, overall completion and ceremony readiness; test dependencies and optional skips."

### Prompt 3 — student impact
"Build milestone detail forms, resources, simulated RSVPs, five crests, next chapter planning and private reflection UI with all screen-level states and validation."

### Prompt 4 — presentation polish
"Bring all screens up to Expressive Collegiate Editorial spec, tune desktop/mobile, build dignified final destination, reduced-motion fallback, demo scenario resets and no-dead-buttons QA."

### Prompt 5 — readiness
"Run tests, validate content and assets, fix regressions, produce offline fallback instructions and a judge-ready self-test checklist; list any unresolved approved asset dependencies clearly."
