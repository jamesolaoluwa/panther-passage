# Panther Passage — Cursor foundation

**100 DAYS OF BECOMING** · Philander Smith University Last 100 Days HBCU Challenge concept.

This is a **documentation, data, and original illustrative SVG package**, not a runnable application. Open this folder in Cursor and read `12_Cursor_Handoff/START_HERE.md` followed by `CURSOR_MASTER_INSTRUCTIONS.md`.

## Product promise
A campus-rooted digital passage through fifteen preparation milestones in five chapters, balancing aspiration, practical readiness, connection, reflection and legacy. The pathway map is inspired by the accessibility of casual-game progression but has an independent premium collegiate art direction. No artificial failure states or manipulative streaks.

- Confirmed from project conversation: name, competition context, expressive collegiate editorial direction, 100 Days of Becoming framing, Candy Crush-inspired *navigation pattern*, desired less-green campus scene, approved logo exists and should be retained, white-background slide direction, welcome supporting sentence.

## Demo operating model
Fictional profiles and events, no production university login, local browser persistence and switchable seed scenarios. Graduation date is configurable; calendar countdown is not earned progress.
