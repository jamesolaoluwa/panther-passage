# Visual direction — Expressive Collegiate Editorial

**Visual reference priority**: latest user-approved Panther Passage original logo > user-selected photorealistic map > updated welcome reference > earlier concept versions.

**Look:** believable red-brick architecture, restrained trees, lawns and walkways, elevated three-quarter perspective, subdued physical lighting and subtle depth. The centerpiece is a winding path, not a university dashboard. UI surfaces are generally Warm Ivory; use Evergreen and Gold as selective accents. Never fill every space with floating objects, trees or ornamental shapes.

**Brand:** Stitch-textured, dimensional green-and-gold varsity logo. Never regenerate or substitute if faithful use is possible; no animal, no horizontal rules, no extra tagline.

**Text:** exact readable text remains React text. Logo remains raster PNG until editable source supplied. Typeface direction: expressive college-editorial with modern accessible body font; actual licensed font binaries are not included. Recoleta-inspired display and DM Sans/Clash-style functional text were discussed, but fonts must be licensed and selected during implementation.

**Map:** completed badges show labels; locked badges show lock alone until unlocked. Distinguish status with icon + text in accessible overlays.
