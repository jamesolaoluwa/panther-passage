**Source of truth:** `01_Branding/Logos/Panther_Passage_APPROVED_Logo_Original.png` is the user-selected brand artwork and is copied unchanged. **Use now:** Integrate SVG medallions and paths in React; use the raster mockups only for preview. Implement words, buttons and click targets as actual DOM/React UI, not flattened artwork. See `11_Cursor_Handoff/ASSET_IMPLEMENTATION_GUIDE.md`.

Previously generated raster mockups may contain baked text and cannot be treated as accurate composited UI backgrounds.
